# 森林小屋 3D (Forest Cabin 3D)

这是一个完全由 AI 辅助生成的沉浸式 3D 交互式网页体验。

## 🌲 在线体验
点击下方链接，即可直接在浏览器中游玩（支持手机和电脑）：
👉 [点击这里进入森林小屋](https://1829069796wz-tech.github.io/forest-cabin-3d-/)

## ✨ 功能特点
- 纯 HTML/WebGL 实现，无需下载任何插件。
- 支持鼠标拖拽旋转视角、滚轮缩放。
- 黄昏时分松林深处的静谧氛围感。
- 支持点击灯笼等环境交互。

## 🛠️ 技术栈
- AI 大语言模型（辅助生成代码）
- HTML5 / Canvas / WebGL
